# 🧮 Simple Calculator

## 📌 Overview
A responsive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations through a clean and easy-to-use interface.

## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- Responsive layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download the project.
2. Open `newname.html` in any web browser.
